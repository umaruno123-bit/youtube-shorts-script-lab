# テロップ作成マニュアル(Canva版)

台本を動画のテロップ(字幕)として画面ごとに分割する際のルール。
`shortslab prepare` が生成するClaude Code向け指示書の「テロップ分割」タスクで
このルールをそのまま使う。

## 基本フォーマット

- キャンバスサイズ: 縦型動画(アスペクト比9:16)
- 配置: 画面中央(または指定の定位置)
- 1画面の行数: 基本1〜2行(最大でも3行まで)
- 1行の文字数: 12文字まで

## テロップを「区切る(画面を切り替える)」4つの法則

台本をそのまま流し込むのではなく、「意味のまとまり(ブロック)」ごとに分解して
1画面ごとのテロップを作る。

- **法則1: 接続詞は「単独」で表示する(重要)** — 「そもそも」「しかし」「結果として」「なお」などの言葉は、前後の文と絶対に混ぜず、1画面に単独で短く表示する。動画のリズムを作る重要なフックになる。
- **法則2: 主語・テーマ(〜は、〜とは、〜が)で区切る** — 「今から何について話すのか」を提示するブロックは、助詞(は・とは・が)の直後で区切る。
- **法則3: 修飾語(説明)と名詞(結論)を分離する** — 「〜する〇〇」「〜な〇〇」という文章は、一気に表示させず、「説明部分」と「結論の名詞」で画面を分割する。
- **法則4: 状況・場所(〜において、〜では)で区切る** — 場所や前提条件を説明する言葉も、そこで一旦区切ることで視聴者の頭に情景が浮かびやすくなる。

## テロップ内での「改行」ルール

1画面の中で2行以上に分ける場合は以下を守る。単語の途中で不自然に改行すると
視聴者のストレスになる。

- 意味のまとまり(文節)で改行する
- 助詞(て・に・を・は・が、など)の後で改行する
- カギカッコ「」内のセリフが長い場合は、1画面に詰め込まず意味の区切りで2画面に分割する

## 分解サンプル

**サンプル①(基本の4分割)**
元の台本: 「そもそも水泳において水の抵抗とは選手の体力をゴリゴリ削り取る最悪の確定デバフなのだが」
- 1画面目: そもそも (法則1: 接続詞)
- 2画面目: 水泳において水の抵抗とは (法則2: テーマ)
- 3画面目: 選手の体力をゴリゴリ削り取る (法則3: 修飾語)
- 4画面目: 最悪の確定デバフなのだが (法則3: 名詞・結論)

**サンプル②(説明文の連続分割)**
元の台本: 「世界のトップ審判たちが完全に依存する音響兵器モルテンの笛は」
- 1画面目: 世界のトップ審判たちが (法則2: 主語)
- 2画面目: 完全に依存する音響兵器 (法則3: 修飾語)
- 3画面目: モルテンの笛は (法則2: テーマ)

**サンプル③(長い状況説明の分割)**
元の台本: 「10円値上げしただけで全国民に土下座したガリガリ君の製造元の赤城乳業は」
- 1画面目: 10円値上げしただけで (法則4: 状況)
- 2画面目: 全国民に土下座した (法則3: 修飾語)
- 3画面目: ガリガリ君の製造元の赤城乳業は (法則2: テーマ)

## Canvaでの推奨作業ステップ(参考)

1. 音声の配置とテキストの流し込み
2. 音声に合わせたスプリット(分割)
3. スマホプレビューでの最終確認(文字が小さすぎないか、表示時間が短すぎないか、単語の途中で改行されていないか)
